ขั้นตอนที่ 1: เตรียมไฟล์ — ยังไม่เผยแพร่
ปุ่มด้านล่างสร้างชุดอัปเดตให้คุณนำขึ้น GitHub จากนั้น Vercel จึงเผยแพร่ ไม่ต้องใส่รหัสผ่านหรือคีย์เชื่อมต่อในหน้านี้

เตรียมใบงานใหม่สำหรับลงเว็บ

ใส่ PDF และข้อมูลใบงาน แล้วดาวน์โหลดชุดอัปเดตเพื่อนำขึ้น GitHub Desktop ข้อมูลในหน้านี้ยังไม่ถูกเผยแพร่จนกว่าคุณจะ Commit และ Push

กำลังอ่านรายการใบงานปัจจุบัน…

ใช้รายการล่าสุดเสมอ เพื่อไม่ให้ใบงานที่เคยเพิ่มหายไปเมื่อแทนที่ไฟล์

เลือกใบงานเดิมเพื่อแทนที่ โดยคงรหัสรายการเดิมไว้และทำให้ลิงก์ใบงานยังเปิดได้ ไฟล์ชุดอัปเดตยังต้องนำขึ้น GitHub เพื่อเผยแพร่

นำขึ้นเว็บใน 4 ขั้นตอน

  1. แตกไฟล์ ZIP จะได้ assets/library.json, assets/catalog/, sitemap.xml และ assets/worksheets/ไฟล์ใหม่.pdf
  2. วางโฟลเดอร์ assets และ sitemap.xml รวมกับไฟล์ใน repository somutrongrian-website ใน GitHub Desktop รวมโฟลเดอร์และแทนที่ไฟล์ชื่อเดียวกันในชุดอัปเดต รวมถึง library.json สารบัญ catalog และ sitemap.xml
  3. ตรวจรายการ Changes → ใส่ข้อความ เช่น “เพิ่มใบงานประจำวัน” → Commit to main → Push origin
  4. เปิด Vercel รอการเผยแพร่สถานะ Ready แล้วเปิดคลังใบงานบนโดเมนจริง ตรวจชื่อเรื่อง ตัวอย่าง และดาวน์โหลด PDF ก่อนถือว่าอัปเดตสำเร็จ

การดาวน์โหลด ZIP ยังไม่เปลี่ยนเว็บไซต์ หน้านี้ไม่เชื่อมต่อบัญชี GitHub และไม่มีการรับไฟล์ PDF เข้าเซิร์ฟเวอร์โดยตรง หากเพิ่มหลายใบงาน ให้ใช้ library.json ฉบับที่เพิ่งดาวน์โหลดเป็นฐานของใบงานถัดไป
