# สมุดโรงเรียน.online — V6.3

เว็บ HTML แบบ static พร้อมนำขึ้น GitHub Pages หรือโฮสติ้งทั่วไป

## ไฟล์
- `index.html` — หน้าเว็บ พร้อม CSS และ JavaScript เดิม
- `assets/images/` — ภาพทั้งหมดของเว็บไซต์
- `IMAGE-NOTES.md` — ที่มาและคำอธิบายภาพ
- `.nojekyll` — ให้ GitHub Pages เสิร์ฟไฟล์ static โดยตรง

## เปิดดู
เปิด `index.html` ในเบราว์เซอร์ได้โดยตรง ต้องใช้อินเทอร์เน็ตเพื่อโหลดฟอนต์ Google Fonts หากโหลดไม่ได้จะใช้ฟอนต์สำรอง

## ขึ้น GitHub Pages
1. สร้าง repository แล้วอัปโหลดไฟล์และโฟลเดอร์ทั้งหมดนี้ไว้ที่ราก repository
2. ไปที่ Settings → Pages เลือก Deploy from a branch และ branch ที่อัปโหลด เลือก / (root) แล้ว Save
3. เมื่อตั้งค่าโดเมน ให้ใส่ชื่อโดเมนใน Custom domain และตั้ง DNS ตามค่าที่ GitHub Pages แสดง
4. เปิด Enforce HTTPS เมื่อระบบออกใบรับรองสำเร็จ

ใส่ CNAME สำหรับ สมุดโรงเรียน.online (xn--72czq3aheb5c3fza5gva.online) แล้ว ต้องตั้งค่า GitHub Pages และ DNS ก่อนจึงจะเปิดผ่านโดเมนได้

## ขอบเขต V6.3
เปลี่ยนเฉพาะภาพการ์ด 3 ใบแรก: เครื่องพิมพ์ระบบม้วน, สต็อกกระดาษม้วน, สมุดสำเร็จรูป และปรับตำแหน่งภาพในกรอบให้เห็นวัตถุชัด
ข้อความ โครงสร้าง ฟอร์ม และ JavaScript เดิมยังอยู่ครบ ภาพในโฟลเดอร์ถูกแยกจาก HTML เพื่อจัดการง่ายขึ้น
