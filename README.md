# สมุดโรงเรียน.online — V7

## หน้าเว็บ
- index.html: หน้าแรก ทางเข้าสองหัวข้อ และบริการผลิตสมุดเดิม
- worksheets.html: ใบงานฟรีและเครื่องมือครู
- support.html: ขอความอนุเคราะห์และแจ้งความสนใจสนับสนุน
- assets/community.js: เครื่องมือสร้าง PDF A4 และฟอร์มคำขอ
- assets/library.json: รายการสื่อและวันที่เผยแพร่
- worksheet-manager.html: เตรียมไฟล์ใบงานใหม่สำหรับนำขึ้น GitHub

## เพิ่มใบงานรายวัน
1. เปิด worksheet-manager.html ผ่านเว็บไซต์ หรือเปิดไฟล์นี้จากเครื่อง
2. หากเปิดจากเครื่อง ให้นำเข้า assets/library.json เวอร์ชันล่าสุดก่อน
3. เลือก PDF ระบุชื่อ ระดับชั้น วิชา คำอธิบาย และวันที่
4. ดาวน์โหลด ZIP ชุดอัปเดต แล้วแตกไฟล์
5. คัดลอก assets ทั้งโฟลเดอร์ไปวางรวมกับ repository ใน GitHub Desktop ให้ library.json ถูกแทนที่ด้วยฉบับใหม่
6. ตรวจ Changes แล้ว Commit และ Push origin รอ Vercel เผยแพร่ (เมื่อเชื่อม repository แล้ว)

หน้าเตรียมไฟล์ไม่ใช่ระบบอัปโหลดเข้าเซิร์ฟเวอร์โดยตรง ไม่มีรหัสผ่านหรือโทเคน GitHub ฝังในเว็บ หน้าเว็บหลักอ่านรายการจาก library.json และเรียงวันที่ใหม่ก่อน ไม่เปลี่ยนวันที่อัตโนมัติเพื่อให้ดูเหมือนมีสื่อใหม่

## การทำงาน
เครื่องมือสร้าง PDF ทำงานในเบราว์เซอร์ ไฟล์ PDF เป็นภาพความละเอียดสูงขนาด A4 รองรับข้อความไทย
คลังใบงานใช้เนื้อหาต้นฉบับคงที่จาก assets/content แยกตามชั้น สร้าง PDF และแนวคำตอบในเบราว์เซอร์เมื่อดาวน์โหลด ไม่เรียก AI และไม่คิดค่าบริการต่อครั้ง ใบงาน PDF ชุดเดิมยังคงใช้งานได้
ฟอร์มขอสนับสนุนและฟอร์มองค์กรสร้างสรุปและเปิด mailto เพื่อให้ผู้ใช้ส่งเองถึง zeeareerat@gmail.com ยังไม่มีฐานข้อมูลรับคำขอหรือสถานะติดตาม และไม่มีการส่งผ่าน FormSubmit
หนังสือขอความอนุเคราะห์ที่ดาวน์โหลดเป็นร่างสำหรับโรงเรียนตรวจและรับรองก่อนแนบอีเมล
ต้องยืนยันโครงการและรายละเอียดก่อนผลิต ไม่มีการรับเงินผ่านเว็บหรือแสดงจำนวนผู้ได้รับการสนับสนุนที่ไม่ได้ตรวจสอบ

## ข้อมูลโรงเรียน
ชื่อ สังกัด รหัสสถานศึกษา ที่อยู่ จังหวัด รหัสไปรษณีย์ ชื่อผู้อำนวยการ ชื่อ/ตำแหน่ง/ช่องทางติดต่อผู้ขอ นักเรียนแยกช่วงชั้น จำนวนผู้ขอรับ จำนวนสมุด งบสมทบ เหตุผล และวันที่ใช้สมุด ไม่เก็บรายชื่อนักเรียน

## โฮสติ้ง
Vercel: Import repository somutrongrian-website, Framework Preset Other, Root Directory ราก repository, ไม่มี build command และ Output Directory .

ชื่อหน่วยเป็นหน่วยคลังของเว็บ ไม่ใช่สารบัญที่ใช้เหมือนกันทุกโรงเรียน ไม่อ้างครอบคลุมรายวิชาเพิ่มเติมทุกแผนการเรียน หรือได้รับการรับรองหลักสูตร ครูควรตรวจและปรับก่อนใช้
assets/worksheet-coverage.csv เป็นสารบัญตรวจจำนวนตามชั้น วิชา และหน่วย
assets/fixed-worksheets.js จัดหน้า A4 รองรับหลายหน้า มีภาพตัวอย่างหน้าแรก ไฟล์ PDF เป็นภาพข้อความไทย ไม่ใช่ข้อความที่เลือกคัดลอกได้
เปิดพรีวิวผ่านเว็บเซิร์ฟเวอร์ เช่น Vercel เพื่อให้โหลดข้อมูล JSON ได้ การดับเบิลคลิก HTML ผ่าน file:// อาจโหลดคลังไม่ได้
หากเพิ่มเนื้อหา JSON เอง ให้เพิ่ม record ใน assets/library.json พร้อม contentId/contentFile และเนื้อหาใน assets/content/<ชั้น>.json โดยให้ id ตรงกัน มี questions พร้อม prompt และ answer ทุกข้อ หรือใช้หน้าเตรียมไฟล์อัปโหลด PDF ตามขั้นตอนด้านบน
